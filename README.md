## ⚙️ Getting Started

Clone the repository:

```bash
git clone https://github.com/ahmed-x-dev/portfolio.git
```

Navigate to the project:

```bash
cd portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```

---

## 📦 Build

Create a production build:

```bash
npm run build
```

Run the production server:

```bash
npm start
```
